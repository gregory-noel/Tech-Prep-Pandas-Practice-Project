# Tech-Prep-Pandas-Practice-Project
TechPrep Web Project to practice reading a file and analyzing data

The Python project should do the following
Read the CSV file Grades_Short.csv 
Calculate the average of several columns
add the averages to a new column
define a function to assign letter grades to the averages
add the grades to a new column
export the files to a new CSV

To determine the letter grade
Final grade equal to or greater than 90 is an "A+"
Final grade equal to or greater than 80 is an "A"
Final grade equal to or greater than 70 is a "B"
Final grade equal to or greater than 60 is a "C"
Final grade greater than 55 is a "D"
Final grade less than or equal to 55 is an "F"
